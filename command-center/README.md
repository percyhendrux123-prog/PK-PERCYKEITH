# PK Command Center

This is Percy's strategy + build + mentorship space, run with Claude.

Start here, but the real brain is the root **`CLAUDE.md`** — it loads automatically
every session and defines who we are, how we work, and how we talk.

## How to use it

- **Just talk.** Open a session and say what's on your mind — a task, a half-idea,
  a hard day. The agent reads `CLAUDE.md` and the relevant playbook below.
- **Point at a workstream** when you know the lane: "let's do content," "client comms,"
  "growth," "mentor me on X."
- **Say "spawn a team"** (or I'll suggest it) when a job is big enough to parallelize —
  see `playbooks/team-dispatch.md`.

## Living document rule

When something real changes — a new offer, a price, a win, a hard lesson — we write
it down in the right file (and `CLAUDE.md` if it's foundational). The value compounds.
